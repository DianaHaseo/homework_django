# Домашняя работа с Django

## Описание:

Домашняя работа по обработке и проверки работоспособности фраемворк

## Установка зависимостей

Создайте и активируйте виртуальное окружение.

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Настройка PostgreSQL

Создайте пользователя PostgreSQL и базу данных.

Скопируйте `.env.example` в `.env`.
Заполните параметры подключения к своей базе данных.

Настоящий `.env` не добавляется в репозиторий.

## Подготовка базы

```bash
python manage.py migrate
python manage.py createsuperuser
```

## Загрузка тестовых данных

```bash
python manage.py load_test_data
```

Внимание: команда удаляет существующие продукты и категории,
затем загружает данные из фикстур.

Для загрузки фикстур без предварительной очистки:

```bash
python manage.py loaddata catalog/categories.json catalog/products.json
```

## Запуск

```bash
python manage.py runserver
```

## Медиафайлы

Изображения загружаются через административную панель
и сохраняются в папке `media/products/`.

Фикстуры не содержат сами файлы изображений.
