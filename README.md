# Домашняя работа с Django

## Описание:

Домашняя работа по обработке и проверки работоспособности фраемворк

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/DianaHaseo/homework_django
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Тестирование

Тестирование нам нужно для проверки правильности выполнения кода.

Для проверки кода можно использовать следующие команды:

Проверка работоспособности сайта.

```
python manage.py runserver
```
